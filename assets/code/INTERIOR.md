# 실내와 가구 배치 규칙

실제 가구 모델 없이 **종류·가로·세로·높이**로 배치를 계산합니다.
`interior_rules.py`는 Blender 없이 실행되고, `interior_blender.py`는
계산 결과를 층별 바닥·칸막이·계단과 이름이 붙은 크기 상자로 그립니다.

## 평면과 층 연결

- **2~3층:** 한쪽에 계단실을 두고, 1층은 거실·식사 공간, 위층은 침실로
  구성합니다. 계단실과 각 방 사이에 문 구멍을 만듭니다.
- **1층:** 공간이 충분하면 침실과 거실을 나눕니다. 좁으면 원룸으로
  전환합니다.
- 실제 외부 출입문 위치를 읽고, 앞쪽의 공용 이동 공간을 먼저 비웁니다.
- 계단은 U자로 꺾이는 두 구간과 중간참으로 구성합니다. 층 높이에서
  계단 수·단높이를 계산하고, 위층 바닥에는 실제 계단 구멍을 냅니다.
- 위층 계단 구멍의 세 면에 난간을 만들고 출입하는 앞쪽은 열어 둡니다.
- 아주 작은 평면에 계단과 방을 함께 넣을 수 없으면 오류를 보고합니다.
  이때 기존 생성 결과는 교체하지 않습니다.

현재 평면은 이 단순한 구성을 사용합니다. 여러 침실·주방·욕실의 조합이나
일부 공간만 위층인 로프트 평면은 포함하지 않습니다.

## 가구별 규칙

| 종류 | 기본 크기: 가로 × 세로 × 높이 (m) | 배치 규칙 |
|---|---|---|
| 침대 `bed` | 1.45 × 2.0 × 0.55 | 머리 쪽을 벽에 붙이고 발치 접근 공간 확보 |
| 등잔 `lamp` | 0.28 × 0.28 × 0.65 | 침대 머리 쪽 좌우 중 들어가는 위치에 배치 |
| 옷장 `wardrobe` | 1.2 × 0.6 × 1.85 | 벽에 붙이고 앞쪽 접근 공간 확보; 창문 가림 방지 |
| 소파 `sofa` | 1.75 × 0.8 × 0.85 | 등받이 쪽을 벽에 붙이고 앞쪽 접근 공간 확보 |
| 의자 `chair` | 0.5 × 0.5 × 0.85 | 책상·식탁을 바라보고, 의자 뒤쪽에 접근 공간 확보 |
| 식탁 `dining_table` | 1.2 × 0.75 × 0.75 | 의자 두 개를 마주 보게 연결하여 함께 배치 |
| 책상 `desk` | 1.1 × 0.6 × 0.75 | 벽에 붙이고 앞쪽 의자 한 개와 함께 배치 |

침대와 등잔, 책상과 의자, 식탁과 의자 둘은 하나의 배치 묶음으로 검사합니다.
등잔은 바닥에 놓는 임시 상자이며 협탁은 아직 생성하지 않습니다.
식탁과 책상의 접근 공간은 연결된 의자 뒤쪽 공간으로 계산하므로 카탈로그의
`clearance` 값은 `0`으로 둡니다.

## 배치 검사

1. 방 경계·칸막이 문·계단·계단참·앞쪽 공용 통로를 결정합니다.
2. 큰 가구부터 종류별 후보 위치와 90도 단위 회전을 검사합니다.
3. 가구 상자가 방 밖으로 나가거나 다른 가구·통로·계단을 침범하면
   후보에서 제외합니다.
4. 접근 공간이 방 안에 있고 다른 가구에 막히지 않는지 검사합니다.
5. 가구 높이가 창문턱보다 높으면 창문 안쪽의 확보 공간도 비워 둡니다.
6. 방 입구에서 각 가구의 접근 지점까지 지정 폭의 정사각형이 이동할 수
   있는지 격자 탐색으로 검사합니다. 창·문·계단 관련 공간은 먼저 예약합니다.

조건을 만족하는 후보가 없으면 가구를 강제로 축소하거나 겹쳐 놓지 않습니다.
해당 종류와 이유를 `unplaced`에 기록하고 Blender 패널에 미배치 개수를
표시합니다. 기본 집에서는 모든 종류가 배치되지만, 크기와 Seed를 바꾸면
공간이 부족한 가구가 생길 수 있습니다.

이 배치는 후보 탐색을 이용한 게임용 블록아웃입니다. 방을 최대한 채우는
전역 최적화나 문 여닫는 애니메이션은 포함하지 않습니다. 칸막이 문은
문짝이 없는 통과 구멍으로 생성합니다.

## 가구 크기 변경

`presets/furniture_sizes.json`을 복사해서 수정한 뒤 Blender 패널의
**가구 크기 JSON**에 지정합니다. 일부 종류만 적으면 나머지는 기본값을
사용합니다. 카탈로그를 수정한 뒤 **집 생성 / 갱신**을 누르세요.

```json
{
  "bed": {"size": [1.6, 2.1, 0.6]},
  "wardrobe": {"size": [1.4, 0.65, 1.9], "clearance": 0.8}
}
```

`size`는 양수인 숫자 세 개이며 단위는 m입니다. `clearance`는 접근 여유
거리이고, 접근 공간이 필요한 가구에는 설정한 통로 폭 이상을 확보합니다.
카탈로그에 모델 파일은 필요 없습니다.

## Blender에서 실내 보기

1. **실내 구조 생성**, **가구 배치**를 켜고 집을 생성합니다.
2. **살펴볼 층**을 선택하고 **선택한 층 실내 보기**를 누릅니다.
3. 외벽·지붕과 다른 층이 숨겨지고, 선택한 층에는 낮은 벽과 가구가 보입니다.
4. **미리보기 카메라 / 조명 만들기**를 누르면 해당 층에 구도를 맞춥니다.
5. **외관 다시 보기**로 전체 건물을 복구합니다.

보기 전환은 생성된 오브젝트의 뷰포트·렌더 표시만 바꿉니다. 사용자가 추가한
오브젝트와 저장된 배치 좌표에는 영향을 주지 않습니다. 현재 실내 보기 층은
갱신할 때도 유지합니다.

## JSON 내보내기와 나중에 모델 연결

```powershell
$emptyScene = 'import bpy; bpy.ops.wm.read_factory_settings(use_empty=True)'
& $blenderExe --background --factory-startup --python-exit-code 1 `
  --python-expr $emptyScene `
  --python assets/code/house_generator.py -- `
  --config assets/code/presets/medieval_house.json `
  --furniture-catalog assets/code/presets/furniture_sizes.json `
  --output assets/generated/my_interior.blend `
  --layout-output assets/generated/my_layout.json `
  --view-floor 2
```

위 명령은 새 백그라운드 Blender의 빈 장면에서 시작합니다. 이미 열려 있는
Blender 창에는 영향을 주지 않습니다.

일반 Python에서도 `--dry-run` 결과의 `interior` 항목으로 같은 배치를
확인할 수 있습니다. 별도 Python 패키지는 필요 없습니다.

JSON에는 방·칸막이·계단·예약 공간·가구·미배치 사유가 들어갑니다.

- 좌표는 `CH_House`를 기준으로 한 로컬 좌표이며 단위는 m입니다.
- `floor`와 계단의 층 번호는 **0부터 시작**합니다. UI와 `--view-floor`는
  **1부터 시작**합니다.
- 가구 `position`은 **바닥면의 중심**, `rotation_z`는 도 단위입니다.
- 모델의 앞 방향은 로컬 **-Y**, 위 방향은 **+Z**입니다.
- `size`는 회전하기 전 모델의 가로·세로·높이입니다.
- `anchor_id`는 등잔이 연결된 침대나 의자가 연결된 책상·식탁을 가리킵니다.
- Blender 상자에도 `furniture_kind`, `size`, `room_id`, `anchor_id` 및
  모델 기준점 정보가 Custom Properties로 저장됩니다.

나중에 가구 모델을 가져올 때는 이 크기·기준점·앞 방향에 맞추고 상자의
위치·회전을 사용하면 됩니다. 실제 모델을 자동으로 찾아 교체하는 자산
라이브러리 연결은 아직 포함하지 않습니다.
